## 二、拟扩写内容（简历正文草案）

### B. AI 研发效能体系（自建）

#### 自研 Agent Skill

**`product-manager` · 产品经理 Agent**
- 扮演资深产品经理解决「页面不好看、功能不好用」类需求，六阶段流程：**需求访谈 → 现状诊断 → 方向提案 →【检查点：选方向】→ 深化方案 →【检查点：批方案】→ 原型构建 → 存档交付**，两道检查点未获批不得推进
- 需求访谈围绕「核心痛点 / 目标用户与场景 / 约束与期望」一次一问，信息足够即收手
- 现状诊断双场景：**存量页面翻新**（浏览器实测登录系统 + 整页与关键区域截图留档 + 按路由定位组件 + 输出四维度诊断清单）与**全新功能**（入口侦察 + 规范摸底 + 参考分析）
- 产出**《后端需求清单》**：接口路径、改动类型、字段定义、出入参示例，可直接转交后端；含糊表述被明令禁止
- 产出**可点击 HTML 原型**：读取项目主题变量注入色板（不硬编码，换肤自动跟随），核心交互真实可用；自检含 CDN 资源加载、控制台无报错、截图与方案比对
- **职责边界止于方案与原型，不修改业务代码**；问题性质若从「不好」变为「坏了」，自动移交 bug-repairer

**`bug-repairer` · Bug 根因分析 Agent**
- **双 Bug 系统自动识别**：按 URL 判别禅道 / 云效并匹配对应登录态，适配两套系统的页面结构差异
- **代码优先于复现**，按确信度分级处置：100% 确定（纯逻辑错误）直接定位修改；80-90% 确定用接口拦截确认数据结构；低于 80% 才走完整浏览器复现
- 内置 **AES-128-ECB 接口解密**与 XHR 拦截一体化脚本，可直读加密响应原始数据
- **前后端归因四条件判定**（数据直达 / 同源对照 / 模板无误 / 无遗漏处理），四者全满足才判定为后端问题，并输出从 API 响应到模板显示的完整证据链
- 修复后**强制浏览器验证** + **同组件影响面检查**（反查路由复用，评估波及范围）
- 内置浏览器工具降级策略：Playwright MCP 连接异常时自动切换 Chrome DevTools MCP 并全程保持，附完整工具对照表

**`exporting-user-data` · 批量数据导出 Agent**
- 一条命令完成：登录态复用 → **526 家单位全量用户拉取** → Excel（总索引 + 每单位一页签）→ **回读自校验**
- 5 并发约 2 分钟完成全量拉取；页签名自动截断去重以符合 Excel 限制
- 校验不通过（退出码 1）禁止交付；内置「易错点清单」沉淀踩坑经验

#### SubAgent 与端到端回归
- **考试流程测试 Agent**：自动完成登录 → 考试码入场 → **6 个页签作答**（基本信息 / 中医诊断 / 辨病辨证 / 病症鉴别 / 中医治法 / 中药处方）→ 提交 → 成绩核验；逐项比对「实际作答」与「成绩页学生答案」以验证**判分逻辑正确性**，自动生成含阶段截图、作答数据与验证清单的 HTML 报告
- **多子代理协作流水线**：按「实施 → 规格审查 → 代码质量审查」分工，21 个子代理单轮运行 4 小时产出 641 行有效变更
- **浏览器自动化实测**：Playwright / Chrome DevTools MCP 采集无障碍快照、控制台与网络请求，形成可追溯的验证证据链

#### 规格驱动工作流：先与 AI 确认文档，再动手实施
- 每个功能按「**设计规范 → 实施计划 → 分步实施 → 逐项验收**」四段推进，每段独立留痕，可回溯可审计
- 设计文档交付前先做**规范自审**：占位符扫描、内部一致性、范围控制、歧义排查四项自检
- 阶段检查点不可逾越，未获批准不进入下一阶段

#### 工程化沉淀
- 建设项目上下文记忆库（六类文档：项目概要 / 产品背景 / 技术上下文 / 系统模式 / 活动上下文 / 进度）与七份团队规范库
- 开发 **Vue2 → Vue3 迁移自动化三件套**（质量分析器、批量修复执行器、稳定修复器），支持 dry-run 与自动备份
- 沉淀自定义命令集：病例编辑、练习配置、考试流程验证、多角色登录等高频场景
